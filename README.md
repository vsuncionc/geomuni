# Geomuni

Landing page responsive para una tienda de flores, construida con HTML, CSS y JavaScript vanilla. Incluye catálogo, carrito lateral funcional y diseño adaptable a móvil.

## Ejecutar localmente

No requiere instalación ni dependencias. Desde la raíz del repositorio puedes abrir `index.html` directamente en el navegador o iniciar un servidor estático:

```bash
python -m http.server 8000
```

Después visita <http://localhost:8000>.
